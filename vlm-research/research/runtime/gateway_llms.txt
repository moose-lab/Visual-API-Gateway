# VLM Run

> The unified gateway for document, image, and video AI. Open-weight vision models behind one OpenAI-compatible API — Orion, our visual agent, sees, reasons, and acts when you need more than raw models.

Key terms: Visual Intelligence, Vision-Language Model, VLM, Orion, Visual Agent, Document OCR, Structured Output, Visual Grounding, HIPAA, SOC 2, Computer Vision, Multimodal AI, Visual ETL, API

## Product

- [Homepage](https://vlm.run): The unified gateway for document, image, and video AI. Open-weight vision models behind one OpenAI-compatible API.
- [Product](https://vlm.run/product): Build, run, and operate visual AI across images, documents, and video with production-grade accuracy, observability, and control.
- [Orion Visual Agent](https://vlm.run/orion): Orion, the visual agent that sees, reasons, and acts on images, video, and documents through a single OpenAI-compatible API.
- [Gateway](https://vlm.run/gateway): The OpenAI-compatible gateway for visual AI. OCR, captioning, detection, and chat behind one endpoint.
- [Gateway Models](https://vlm.run/gateway/models): Visual models on the VLM Run Gateway: OCR, markdown, captioning, detection, and embeddings behind one OpenAI-compatible endpoint.
- [Frontier Models](https://vlm.run/gateway/models/frontier-models): Frontier models the gateway routes to an upstream provider, so one key and one OpenAI-compatible endpoint cover them as well.
- [Document AI](https://vlm.run/doc-ai): Document intelligence for the agentic stack. Schema-validated JSON with grounding from PDFs and scans.
- [Image AI](https://vlm.run/product/images): Caption, detect, segment, and generate images through one OpenAI-compatible API.
- [Video AI](https://vlm.run/video-ai): Summarize, transcribe, and search video with time-anchored structured output.
- [Physical AI Demo](https://vlm.run/demos/physical-ai): Side-by-side Orion dense segmentation on robot padlock-unlock episodes.
- [Pricing](https://vlm.run/pricing): Dollar billing for Orion agents, models, and tools. Start free with a $10 balance.
- [Chat Playground](https://chat.vlm.run): Try Orion in a hosted chat interface.
- [API Docs](https://docs.vlm.run): Developer documentation, API reference, and quickstart guides.
