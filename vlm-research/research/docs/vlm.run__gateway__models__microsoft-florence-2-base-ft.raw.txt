Supported inputs
textIgnored
A text part beside the media is accepted and ignored. A request with no media part is a 400.
image_urlYes
One per request. A second image_url part is a 400.
video_urlNo
Not accepted.
document_urlNo
Not accepted.
Default method caption. The caption and ocr methods emit a Markdown string; the region methods emit a region container.
Alias: microsoft/Florence-2-base-ft. Weights: microsoft/Florence-2-base-ft.
Methods
Methods this model serves. Payload shapes are in the docs.
MethodReturns
caption (default)Short image caption
detailed_captionLonger caption
more_detailed_captionLongest caption
ocrAll text on the image
odRegion items with bbox_xywh and label
dense_region_captionRegion items with bbox_xywh and label
region_proposalRegion items with bbox_xywh, no label
ocr_with_regionRegion items with bbox_xywh and text
Each method maps to one Florence-2 task token. The task token itself (<CAPTION>, <OD>, ...) is an implementation detail and is not part of the reply: a caption is the string, and a region method is the container.
Boxes are normalized 0-1 against the image at precision decimals (default 4), and a region method with no hits returns "items": [].

Quick start
Call this model on the OpenAI-compatible gateway. The model id is already filled in.
PythonNode.jsCLIcURL
from openai import OpenAI
client = OpenAI(
base_url="https://gateway.vlm.run/v1/openai",
api_key="<VLMRUN_API_KEY>",
)
response = client.chat.completions.create(
model="microsoft/florence-2-base-ft",
messages=[
{
"role": "user",
"content": [
{
"type": "image_url",
"image_url": {
"url": "https://storage.googleapis.com/vlm-data-public-prod/hub/examples/image.caption/car.jpg"
},
},
],
}
],
extra_body={"method": "caption"},
)
print(response.choices[0].message.content)
