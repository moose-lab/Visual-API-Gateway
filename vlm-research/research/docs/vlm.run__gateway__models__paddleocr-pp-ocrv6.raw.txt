About
PP-OCRv6 is a 20M open-weight model from PaddlePaddle. PaddleOCR PP-OCRv6 medium text detection and recognition; scene OCR JSONL on image chat; text returns plain text; document_url fan-out via text. It accepts images and documents. Released June 11, 2026.

Supported inputs
textNo
A request with no media part is a 400.
image_urlYes
One per request. A second image_url part is a 400.
video_urlNo
Not accepted.
document_urlYes
One PDF, up to 128 pages, rasterized per page at document_dpi (default 96). See Document Inputs.
Default method ocr.
Alias: pp-ocrv6.
Methods
Methods this model serves. Payload shapes are in the docs.
MethodReturns
ocrRegion items with bbox_xywh, optional poly_xy, text, score
detectRegion items with bbox_xywh and optional poly_xy, geometry only
textRecognized text stitched in reading order
The payload kind is the same for an image and for each page of a PDF. Text mode emits the payload alone for one image, and one <document> / <page> block for a PDF. In JSON mode an image content is the tagged container above, and a document page content is always doc.page.blocks. See Methods & Response Format.
Coordinates are normalized 0-1 against the image or rasterized page, at precision decimals (default 4). text is plain scene text stitched in reading order, not generative Markdown.
Method parameters
ParameterDefaultDescription
langenRecognition language (en, ch, japan, ...), on every method.
score_threshold0.5ocr and text: drop text regions below this recognition confidence (0.0-1.0). detect returns every region.

Quick start
Call this model on the OpenAI-compatible gateway. The model id is already filled in.
PythonNode.jsCLIcURL
from openai import OpenAI
client = OpenAI(
base_url="https://gateway.vlm.run/v1/openai",
api_key="<VLMRUN_API_KEY>",
)
response = client.chat.completions.create(
model="paddleocr/pp-ocrv6",
messages=[
{
"role": "user",
"content": [
{
"type": "image_url",
"image_url": {
"url": "https://storage.googleapis.com/vlm-data-public-prod/hub/examples/document.receipt/playground/2.jpg"
},
},
],
}
],
extra_body={"method": "ocr"},
)
print(response.choices[0].message.content)
