Default method markdown. All five methods return a text payload; only the subject differs, so table, formula, and chart read a page's tables, equations, and charts rather than its prose.

Methods
Methods this model serves. Payload shapes are in the docs.
MethodReturns
markdown (default)Reading-order page read as Markdown
ocrReading-order plain-text page read
tableThe page's table alone, as OTSL structure tokens
formulaLaTeX for the page's equations (e.g. $$E = mc^2$$)
chartShort description followed by the series as a Markdown table
Note
A gateway build that predates the catalog fix lists only ocr, table, formula, and chart for this model and reports default_method as ocr, while still applying markdown when method is omitted. Send method explicitly whenever the page read matters.
Every method on this model uses the shared contract on Methods & Response Format: <document> / <page id= format= width= height=> in text mode, and the flat reply with top-level model, method and the input's details in JSON mode. The method decides the payload, not the shape.

Quick start
Call this model on the OpenAI-compatible gateway. The model id is already filled in.
PythonNode.jsCLIcURL
from openai import OpenAI
client = OpenAI(
base_url="https://gateway.vlm.run/v1/openai",
api_key="<VLMRUN_API_KEY>",
)
response = client.chat.completions.create(
model="paddlepaddle/paddleocr-vl-1.6",
messages=[
{
"role": "user",
"content": [
{
"type": "image_url",
"image_url": {
"url": "https://storage.googleapis.com/vlm-data-public-prod/hub/examples/document.receipt/playground/2.jpg"
},
},
],
}
],
extra_body={"method": "table"},
)
print(response.choices[0].message.content)
Swap image_url for a document_url PDF to read every page with the same method; markdown is used when method is omitted.
