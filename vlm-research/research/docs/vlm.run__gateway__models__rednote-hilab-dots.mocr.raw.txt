About
dots.mocr is a 3B open-weight model from rednote-hilab. Multilingual document layout parsing and markdown OCR. It accepts text, images, and documents. Context window is 32K. Released March 19, 2026.

Methods
Methods this model serves. Payload shapes are in the docs.
MethodReturns
markdownReading-order Markdown string (default)
ocrPlain OCR text
parse_layoutRegion items with bbox_xywh, label, text
parse_layout_onlyRegion items with bbox_xywh and label, no text
The payload kind is the same for an image and for each page of a PDF. Text mode emits the payload alone for one image, and one <document> / <page> block per PDF, each page declaring its kind in format. In JSON mode an image content is the tagged container above, and a document page content is always doc.page.blocks. Coordinates are normalized 0-1 at precision decimals (default 4). See Methods & Response Format.

Quick start
Call this model on the OpenAI-compatible gateway. The model id is already filled in.
PythonNode.jsCLIcURL
from openai import OpenAI
client = OpenAI(
base_url="https://gateway.vlm.run/v1/openai",
api_key="<VLMRUN_API_KEY>",
)
response = client.chat.completions.create(
model="rednote-hilab/dots.mocr",
messages=[
{
"role": "user",
"content": [
{
"type": "document_url",
"document_url": {
"url": "https://storage.googleapis.com/vlm-data-public-prod/hub/examples/finance.sec-filings/tsla-8k.pdf"
},
},
],
}
],
extra_body={"method": "markdown"},
)
print(response.choices[0].message.content)
