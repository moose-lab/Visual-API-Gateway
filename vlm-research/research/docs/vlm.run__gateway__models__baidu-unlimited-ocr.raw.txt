Methods
Methods this model serves. Payload shapes are in the docs.
MethodReturns
markdown (default)Reading-order Markdown, one <page> block per page
multi_pageContinuous plain text from an 8-page sliding window, no <page> blocks
Both methods return the Markdown-kind payload. multi_page reads an 8-page sliding window per model call by default. Set method_params.window_size to change the window size.
Text mode emits a bare payload string for one image, and one <document> block for a PDF. With markdown, the document contains one <page> block per page of Markdown. The model's own grounding markup is stripped before the reply, so a page reads like any other markdown-kind method. With multi_page, the <document> block carries continuous plain text with no <page> blocks. In JSON mode the reply is the flat document object, with top-level model and method and one record per page under pages. See Methods & Response Format.
Method parameters
ParameterDefaultDescription
window_size8multi_page only: pages read per model call as a sliding window over the document, up to the engine's ceiling of 40.
window_overlap1multi_page only: pages of the previous window re-read as context. Their output is dropped, not billed twice.
window_page_output_tokens1600multi_page only: expected Markdown tokens per page. Raise it for dense pages; the window shrinks to fit.
window_context_tokens32768multi_page only: the model context the window is sized against. Lower it only to leave headroom.

Quick start
Call this model on the OpenAI-compatible gateway. The model id is already filled in.
PythonNode.jsCLIcURL
from openai import OpenAI
client = OpenAI(
base_url="https://gateway.vlm.run/v1/openai",
api_key="<VLMRUN_API_KEY>",
)
response = client.chat.completions.create(
model="baidu/unlimited-ocr",
messages=[
{
"role": "user",
"content": [
{
"type": "document_url",
"document_url": {
"url": "https://storage.googleapis.com/vlm-data-public-prod/hub/examples/finance.sec-filings/tsla-8k.pdf"
},
},
],
}
],
extra_body={"method": "markdown"},
)
print(response.choices[0].message.content)
To read a document in sliding windows, use multi_page and set window_size:
