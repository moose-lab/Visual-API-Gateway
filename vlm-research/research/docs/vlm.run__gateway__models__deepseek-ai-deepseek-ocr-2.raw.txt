One PDF, up to 128 pages, rasterized per page at document_dpi (default 96). See Document Inputs.
Default method markdown. Three methods return the page as a string; grounding_ocr locates a phrase and returns region boxes instead.
Context window 32,768 tokens, with a maximum output of 8,192 tokens.
Weights: deepseek-ai/DeepSeek-OCR-2. Aliases are listed below.
Methods
Methods this model serves. Payload shapes are in the docs.
MethodReturns
markdownReading-order Markdown string (default)
ocrMarkdown via the grounded conversion prompt; grounding tags are stripped from the output
free_ocrFree-form plain read of the page
grounding_ocrRegion items with bbox_xywh and the matched text
Text mode emits the string alone for one image, and one <document> / <page> block per PDF page. In JSON mode an image content is the string, or the region container for grounding_ocr, and a document page content is always doc.page.blocks. See Methods & Response Format.
The model grounds on a fixed 0-1000 grid; the Gateway normalizes every box to 0-1 against the image or rasterized page, at precision decimals (default 4). Grounding regions carry bbox_xywh and text only: no polygon and no score.
Method parameters
ParameterDefaultDescription
promptnonegrounding_ocr only: the full grounding prompt, with the phrase to locate wrapped in the model's ref markers. See Grounding.
Grounding
grounding_ocr answers "where does this appear on the page". Pass the full grounding prompt via method_params.prompt, with the phrase to locate wrapped in the model's ref markers:
PythonNode.jsCLIcURL
response = client.chat.completions.create(
model="deepseek-ai/deepseek-ocr-2",
messages=[
{
"role": "user",
"content": [
{
"type": "image_url",
"image_url": {
"url": "https://storage.googleapis.com/vlm-data-public-prod/hub/examples/document.receipt/playground/2.jpg"
},
},
],
}
],
extra_body={
"method": "grounding_ocr",
"method_params": {"prompt": "<image>\nLocate <|ref|>Total Amount<|/ref|> in the image."},
},
)
The reply is the region container, alone in text mode and under content in JSON mode:
JSON
{"object": "doc.ocr.lines", "items": [{"bbox_xywh": [0.102, 0.08, 0.893, 0.06], "text": "Annual Report 2024"}, {"bbox_xywh": [0.102, 0.16, 0.893, 0.08], "text": "Overview"}]}
On a PDF each page's content is doc.page.blocks, with one block per located region carrying the same bbox_xywh and text.

Quick start
Call this model on the OpenAI-compatible gateway. The model id is already filled in.
PythonNode.jsCLIcURL
from openai import OpenAI
client = OpenAI(
base_url="https://gateway.vlm.run/v1/openai",
api_key="<VLMRUN_API_KEY>",
)
response = client.chat.completions.create(
model="deepseek-ai/deepseek-ocr-2",
messages=[
{
"role": "user",
"content": [
{
"type": "document_url",
"document_url": {
"url": "https://storage.googleapis.com/vlm-data-public-prod/hub/examples/finance.sec-filings/tsla-8k.pdf"
},
},
],
}
],
extra_body={"method": "markdown"},
)
print(response.choices[0].message.content)
