Quick start
Call this model on the OpenAI-compatible gateway. The model id is already filled in.
PythonNode.jsCLIcURL
from openai import OpenAI
client = OpenAI(
base_url="https://gateway.vlm.run/v1/openai",
api_key="<VLMRUN_API_KEY>",
)
with open("sample.mp3", "rb") as audio_file:
response = client.audio.transcriptions.create(
model="nvidia/parakeet-tdt-0.6b-v3",
file=audio_file,
)
print(response.text)
Response
response_format defaults to json, which carries the transcript and a usage block:
JSON
{
"id": "transcription-3d1df87d0037",
"object": "audio.transcription",
"model": "nvidia/parakeet-tdt-0.6b-v3",
"backend": "nemo",
"task": "transcribe",
"duration": 252.726,
"text": "McKeys Rocks is a rough and tumble area just outside Pittsburgh…",
"usage": {
"type": "duration",
"input_audio_seconds": 252.726,
"input_tokens": 0,
"output_tokens": 581,
"total_tokens": 581,
"cost": 0.004213
}
}
usage.cost is the metered charge in USD, and input_audio_seconds is the quantity it was computed from: the clip's duration at $0.06 per audio hour. See Pricing.
Note
Only json and verbose_json carry a usage block. text, srt, and vtt return the transcript alone, so read the cost from one of the JSON formats if you need it.
