## Supported Content Types

| Type | Formats | Limit |
| - | - | - |
| Images | JPG, PNG, WebP | 10MB |
| Documents | PDF | 25MB, 30 pages |
| Videos | MP4 | 100MB |
| Audio | MP3 | 25MB |
