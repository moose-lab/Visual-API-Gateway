# Platform

> Chat with visual agents, build skills, and observe every request.

  <img src="https://mintcdn.com/autonomiai/31N4NFzIelpYJkPB/images/platform-main-page.png?fit=max&auto=format&n=31N4NFzIelpYJkPB&q=85&s=ad225b922eb4fcaea721b95e942e9ecd" alt="VLM Run platform dashboard" width="2712" height="1518" data-path="images/platform-main-page.png" />

* **[Observe](https://app.vlm.run/dashboard/overview)**: Requests, executions, completions, and cost.
* **[Skills](https://app.vlm.run/dashboard/skills)**: What to extract and how to structure the output. Create the skill once. Reference it from any endpoint.
* **[Chat](https://chat.vlm.run/)**: Attach images, PDFs, or videos. Responses are structured.
* **[Evaluations](/platform/observe/evaluations)**: Accuracy for skills, agents, and domains. Feedback is ground truth. Dashboard runs include per-field metrics.
