About
GLM-OCR is a 0.9B open-weight model from Zhipu AI. Compact multilingual document OCR and markdown extraction. It accepts text, images, and documents. Context window is 8K. Released January 30, 2026.

markdown (default)Reading-order Markdown / HTML string
Text mode emits the string alone for one image, and one <document> / <page> block per PDF, each page carrying format="markdown". In JSON mode an image content is the string, and a document page content is doc.page.blocks. See Methods & Response Format.

Quick start
Call this model on the OpenAI-compatible gateway. The model id is already filled in.
PythonNode.jsCLIcURL
from openai import OpenAI
client = OpenAI(
base_url="https://gateway.vlm.run/v1/openai",
api_key="<VLMRUN_API_KEY>",
)
response = client.chat.completions.create(
model="zai-org/glm-ocr",
messages=[
{
"role": "user",
"content": [
{
"type": "document_url",
"document_url": {
"url": "https://storage.googleapis.com/vlm-data-public-prod/hub/examples/finance.sec-filings/tsla-8k.pdf"
},
},
],
}
],
extra_body={"method": "markdown"},
)
print(response.choices[0].message.content)
