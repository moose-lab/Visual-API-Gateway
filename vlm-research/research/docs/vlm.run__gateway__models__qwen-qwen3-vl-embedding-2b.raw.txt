About
Qwen3-VL Embedding 2B is a 2B open-weight model from Alibaba. Multimodal embedding model for text, image, and video inputs. It accepts text, images, and video. Context window is 8K. Released January 7, 2026.

Supported inputs

Quick start
Call this model on the OpenAI-compatible gateway. The model id is already filled in.
PythonNode.jsCLIcURL
from openai import OpenAI
client = OpenAI(
base_url="https://gateway.vlm.run/v1/openai",
api_key="<VLMRUN_API_KEY>",
)
response = client.embeddings.create(
model="qwen/qwen3-vl-embedding-2b",
input="Extract a vector representation for this text.",
)
print(len(response.data[0].embedding))
