About
Qwen3.5 0.8B is a 0.8B open-weight model from Alibaba. Multimodal chat model with up to 64 images or one video per request. It accepts text, images, and video. Context window is 256K. Released March 3, 2026.

Supported inputs
textYes
Text-only prompts are accepted.
image_urlYes
Up to 64 per request, read together as one prompt. See Image Inputs.
video_urlYes
One clip. Tune sampling with video_fps, video_max_frames, and video_resolution at the top level. See Video Inputs.
document_urlNo
A document_url part is a 400 capability error. Use an OCR model such as paddleocr/pp-ocrv6 for PDFs.
Default and only method: free-form chat (no method or method_params). response_format={"type":"json_schema"} is supported.
Context window 262,144 tokens (256K).
The larger qwen/qwen3.8-27b shares the same contract.
Weights: Qwen/Qwen3.5-0.8B.
Methods
Methods this model serves. Payload shapes are in the docs.
MethodReturns
chat (default)The model's reply, verbatim
A chat VLM is pass-through. Text mode returns the reply with no wrapper, even with several images: the model reads them together and produces one reply. JSON mode returns the model's own JSON, with no data envelope. See Methods & Response Format.

Quick start
Call this model on the OpenAI-compatible gateway. The model id is already filled in.
PythonNode.jsCLIcURL
from openai import OpenAI
client = OpenAI(
base_url="https://gateway.vlm.run/v1/openai",
api_key="<VLMRUN_API_KEY>",
)
response = client.chat.completions.create(
model="qwen/qwen3.5-0.8b",
messages=[
{
"role": "user",
"content": [
{"type": "text", "text": "What is happening in this image?"},
{
"type": "image_url",
"image_url": {
"url": "https://storage.googleapis.com/vlm-data-public-prod/hub/examples/image.caption/car.jpg"
},
},
],
}
],
)
print(response.choices[0].message.content)
