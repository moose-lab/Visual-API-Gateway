## Key Features

| Feature | Description |
| - | - |
| **File attachments** | Upload images, PDFs, videos, and audio in the chat window |
| **Skill picker** | Select a skill to constrain outputs to a specific schema |
| **Structured responses** | JSON results with a natural language explanation |
| **Conversation history** | Resume past conversations and iterate on results |
| **Create skills from chat** | Turn a successful conversation into a reusable skill in one click |
| **Real-time streaming** | Responses stream token-by-token |

## From Playground to Production

1. **Explore**: Upload a sample file. Ask Orion a question.
2. **Refine**: Iterate on the prompt. Select or create a skill to structure the output.
3. **Integrate**: Take the skill and model configuration from Chat. Wire them into API calls with the [Python SDK](/sdk-reference/getting-started), [Node.js SDK](/sdk-reference/node/getting-started), or [REST API](/api-reference/v1/post-chat-completions).

Every conversation is logged in [Observe](/platform/observe/overview). Inspect completions, debug responses, and track costs there.
